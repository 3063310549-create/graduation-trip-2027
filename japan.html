行程 02

日本 · 东京—银山—北海道

1月13日—26日 · 14天13晚

路线

  1. 北京
  2. 东京
  3. 银山温泉
  4. 函馆
  5. 札幌
  6. 小樽
  7. 旭川 / 美瑛
  8. 旭岳
  9. 新千岁
  10. 北京

每日安排

D1

1月13日 周三

  1. 北京
  2. 东京
  3. 浅草 / 隅田川

北京飞东京，抵达后进城入住。时间充足时游览浅草寺、浅草老街和隅田川。

住宿
东京
交通
飞机、市内交通、步行；机场和班次待定
D2

1月14日 周四

  1. 明治神宫
  2. 东京国立博物馆
  3. 谷中 / 根津

07:30—08:30 明治神宫；约10:00—12:30 东京国立博物馆；下午谷中、根津。

住宿
东京
交通
市内交通、步行
D3

1月15日 周五

  1. 东京
  2. 大石田
  3. 银山温泉

东京经大石田前往银山温泉。下午入住，日落前后拍摄温泉街，晚上泡温泉。

住宿
银山温泉旅馆
交通
铁路及接驳；旅馆接送待确认
D4

1月16日 周六

  1. 银山温泉
  2. 大石田
  3. 仙台或福岛转乘
  4. 新函馆北斗
  5. 函馆

早餐后退房，全天转场至函馆。经仙台或福岛连接东北新干线，到新函馆北斗后换乘至函馆。

住宿
函馆
交通
接驳、铁路、新干线、市区连接；班次待定
D5

1月17日 周日

  1. 元町 / 教堂群
  2. 八幡坂
  3. 港口
  4. 函馆山

上午元町、教堂群、八幡坂；下午港口旧建筑；傍晚上函馆山。天气不适合时留在港区。

住宿
函馆
交通
市内交通、步行；函馆山交通视运营
D6

1月18日 周一

  1. 五稜郭 / 奉行所
  2. 函馆站
  3. 札幌

上午五稜郭、函馆奉行所；下午乘特急北斗前往札幌。

住宿
札幌
交通
JR特急北斗；指定席待预订
D7

1月19日 周二

  1. 北海道神宫
  2. 开拓村
  3. 北海道博物馆

早晨北海道神宫，随后前往开拓村与北海道博物馆。时间不足时两馆选一。

住宿
札幌
交通
市内轨道交通、巴士、步行
D8

1月20日 周三

  1. 札幌
  2. 小樽 · 旧手宫线
  3. 运河 / 色内
  4. 天狗山

上午前往小樽、寄存行李，游览旧手宫线、运河、色内。傍晚天狗山，缆车停运则留在运河。

住宿
小樽
交通
JR、市内交通、步行；缆车视运营
D9

1月21日 周四

  1. 小樽坡道 / 雪街
  2. 色内旧建筑
  3. 运河
  4. 港口

游览车站周边坡道、雪街、色内旧建筑和旧日本邮船小樽支店一带；下午运河、港口。

住宿
小樽
交通
步行及市内交通
D10

1月22日 周五

  1. 小樽
  2. 札幌
  3. 旭川 / 美瑛

上午经札幌前往旭川或美瑛。下午入住、补给，落实次日交通。

住宿
旭川或美瑛
交通
JR；接续和落脚地待定
D11

1月23日 周六

  1. 美瑛丘陵 / Christmas Tree
  2. 白须瀑布
  3. 青池点灯（可选）

上午美瑛丘陵、Christmas Tree；下午白须瀑布。青池点灯作为可选项目，需安排夜间返程。

住宿
旭川或美瑛
交通
当地包车或其他交通待定；须覆盖夜间回程
D12

1月24日 周日

  1. 旭川 / 美瑛
  2. 旭岳温泉
  3. 旭岳缆车

前往旭岳温泉，缆车运行且天气合适时上山观景。雪鞋活动另约向导；停运时留在温泉区。

住宿
旭岳温泉
交通
当地交通、缆车；接驳待定
D13

1月25日 周一

  1. 旭岳 / 美瑛（可选）
  2. 札幌 / 新千岁附近

上午可选旭岳或美瑛补拍，当天返回札幌或新千岁附近。天气不佳时直接返程。

住宿
札幌或新千岁附近
交通
当地交通及JR；衔接待定
D14

1月26日 周二

  1. 新千岁机场
  2. 北京

前往新千岁机场，飞北京。预留约3小时办理国际出发手续，另计雪天交通时间。

交通
飞机

日本行程使用当地时间，比北京时间快1小时。列车及航班时间尚未确定，住宿按地区列出。

交通与住宿
  • 优先安排银山温泉、旭岳温泉及小樽住宿；银山接送时间需与大石田列车衔接。
  • 银山至函馆经仙台或福岛的换乘方案，按实际班次选择。特急北斗需预订指定席。
  • 旭川或美瑛连住两晚，住宿地点与包车接送点一并安排。美瑛交通需覆盖青池夜间返程。
开放时间与天气
  • 明治神宫1月当前16:20闭门；开拓村、北海道博物馆冬季当前16:30闭馆。2027年开放时间以官方通知为准。
  • 函馆山、天狗山、旭岳缆车受风雪影响；分别以港区、运河、温泉区作为备选。
  • 美瑛青池冬季可能封冻积雪；摄影只在允许停留处，不进入农田。
  • 旭岳冬季观光不包含夏季姿见池环线和登顶；雪地活动需按向导、装备及天气安排。
